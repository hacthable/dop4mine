Help

Using Dopamine

How do I open a site?

Type a web address like youtube.com, or anything you want to search for, then press Enter. Tap a shortcut to jump straight to a site, or the + tile to add your own.

Why won't a site load?

Some sites refuse traffic that comes through a proxy, especially ones with logins, bot checks or video streaming. Try reloading once. If it still fails, the site is probably blocking proxies. Let us know with the form below.

Why does it say "Waking the server up"?

Dopamine runs on a free server that sleeps when nobody is using it. The first visit after a break can take up to a minute, then it works normally.

Why are games slow?

Every file a game loads passes through the server first. Lighter 2D games run best. Big 3D games and cloud gaming services may not work.

Why is a site blocked?

Dopamine does not open adult, piracy, gambling or dark web sites, and every search uses SafeSearch.

Settings and privacy

How do I change the look?

Open Settings in the dock at the bottom. You can change the color, background, clock, menu style, and the tab's title and icon.

Can I install it as an app?

Yes. Use Install in Settings, or your browser's menu. On iPhone or iPad, tap Share, then Add to Home Screen.

Is my browsing private?

Websites see the server's address instead of yours. Your own network can still see that you are using Dopamine, and the server can see who connects. Do not use it for anything illegal. Your settings and shortcuts are saved only in your browser.
